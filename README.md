# Discovery Assistant

Take-home challenge for AdoptAI (Option B: a tool for AdoptAI).

Turns notes or a transcript from a discovery call into a structured brief:
client pains, 2-3 proposals with effort estimates, and a match against
AdoptAI's past-projects portfolio (reuse / adapt / new), for a human to review.

Work in progress. Full README, `AI.md` and time log will be filled in as the build progresses.
